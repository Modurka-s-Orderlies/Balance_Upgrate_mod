# Цель

Идея мода заключается в сбалансированной прокачке игрока. 
Часто (особенно на серверах) игроки лутают какой-нибудь крутой данж из мода, 
багоюзом или хитростью, и без особых усилий получают лучшие вещи. 
В одиночном выживании это не то чтобы проблема, а вот на серверах игрокам, 
которые не успели залутать этот данж, приходиться сутками батрачить чтобы 
догнать этого игрока по силе и весь баланс между фракциями зависит лишь от того, кто успел тот и съел. 
Я предлагаю сделать мод, который фиксит эту проблему, ограничивает доступ к предметам в зависимости от 
их крутости и дающий выбор уникальных абилок 
(некоторыми абилками придется пожертвовать, поэтому игроку придеться думать). 

# ТЗ в общих чертах

В инвентаре игрока, рядом с книгой рецептов, находиться иконка с пиксельной зеленой стрелочкой вверх. 
При нажатии открывается интерфейс прокачки. При наведении меняется текстура стрелочки (смотри textures). Интерфейс будет в ванильном стиле. Пока интерфейс рисуется.
